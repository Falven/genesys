# Domain docs

Genesys uses one domain context.

## Locations

- `GLOSSARY.md` at the repository root defines domain terms.
- `docs/adr/` contains architecture decision records.

Before exploring domain code, read the glossary and relevant decision records.
If those files do not exist, continue without creating them.
The domain-modeling skill creates them when terms or decisions need a record.

## Vocabulary

Use the glossary's terms consistently.
If a required term is absent, report the gap when domain modeling is relevant.

## Decisions

Identify any conflict between proposed work and an existing decision record.
Do not silently replace an accepted decision.
