# Triage labels

Use these strings in each issue's `Status:` line.

| Role            | Status          | Meaning                                   |
| --------------- | --------------- | ----------------------------------------- |
| needs-triage    | needs-triage    | A maintainer must assess the issue        |
| needs-info      | needs-info      | The issue needs more information          |
| ready-for-agent | ready-for-agent | An agent can implement the specified work |
| ready-for-human | ready-for-human | A human must implement the work           |
| wontfix         | wontfix         | The team will not implement the request   |
